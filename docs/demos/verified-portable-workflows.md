On 12 October 2026, the production remote work owner, stock Codex 0.161.0,
Kubernetes placement, home daemon and Docker placement passed the isolated
[portable workflow fixture](../../hack/verify/portable-workflows/README.md).
The dedicated two-node Kind cluster used enforcing Calico and explicit private
kubeconfig selection. No personal infrastructure or paid provider was used.

| Observation | Result and scope |
| --- | --- |

| Remote retention | Native answer `TUI_FIRST_COMPLETE`, observed conversation UUID, actual writer stop, initialized sealed usage and a stored native/Git checkpoint. |

| Scope and lifecycle | Wrong repository, wrong tool and direct provider routes were denied. Stop sealed the final visit; a revoked local worker credential was explicitly denied. |

The real MCP tool was `read_wiki_structure`, restricted to the public
`modelcontextprotocol/go-sdk` repository. The three sealed live-move visits
consumed 2, 1 and 1 admitted MCP units from a ten-call ceiling, leaving six. The
first visit included one preliminary allowed transport call before the full
probe. Denied calls did not consume units. The native UUID and original execution
deadline stayed fixed across those live visits. The later execution's fresh grant
did not renew the earlier remote task's ledger.

The external MCP checks used administrator probes with the actual worker process's
proxy environment, not autonomous model tool selection. The task-submission
caller exercised Hermes's supported native MCP protocol, not a fresh Hermes
harness. Providers for native conversation/tool turns were deterministic TLS
fixtures. These observations do not establish a paid-model Sproozi contribution,
GitHub publication, a personal home-ops diagnosis or remediation, long histories,
compaction, background tools or managed Claude MCP/task completion.

Failed setup attempts retained their original allocation and owner journals.
Unknown preparation/stop/accounting did not permit export or a refund. Behavioral
regressions cover initial helper arguments, default-branch restoration, fresh
project trust, nonblocking replay/export and cancellation after a lost preparation
reply. The [ADR](../adr/0012-retained-work-and-fresh-session-continuations.md)
records decisions and remaining costs; unit and local live proof are separate
from hosted CI and the wider acceptance limits above.
