# Code of Conduct

Participation in this project is governed by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good faith, and keep technical discussions focused on
making the project safer and more useful.

Report unacceptable behaviour by email to
[sproozi-security@andrewmccall.com](mailto:sproozi-security@andrewmccall.com),
with "Sproozi conduct" in the subject. Reports are kept confidential. The maintainer enforces the
Covenant's guidelines and replies within 7 days.
